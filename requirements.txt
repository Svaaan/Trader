# What the Trader needs, and nothing else.
#
# Deliberately no torch. The model HelloWorldAi returns is a small feedforward
# network, and its manifest describes the layers explicitly -- Linear, ReLU,
# Linear -- so running it is a few matrix multiplications. numpy does that in
# twenty lines you can read, instead of a two-gigabyte dependency and a CUDA
# version to match. See src/trader/model.py.
#
# Also deliberately no scikit-learn. The local control models in
# src/trader/baseline.py are a logistic regression and a small MLP, which are
# about a hundred lines of numpy between them. A control you cannot read is not
# much of a control, and the whole point of those models is to be the thing the
# expensive one is checked against.
